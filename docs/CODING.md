# 👨‍💻 Coding-Agent

<details><summary>Fähigkeiten</summary>
Workspace lesen/schreiben, Diffs, Tests, Linting, Fehleranalyse und schrittweise Änderungen.
</details>
<details><summary>Teamwork</summary>
Der Coding-Agent kann später von Atlas geplant werden und Ergebnisse an Reviewer-/Research-Agenten zurückgeben.
</details>
<details><summary>Ausführung</summary>
Keine unkontrollierte Shell-Ausführung als Default. Geplante Ausführung gehört in eine begrenzte Workspace-Sandbox.
</details>
