# 🤖 Agenten

<details><summary>Persona</summary>
Jeder Agent besitzt ID, Name, Rolle, Persönlichkeit, Stimme, Priorität und Kurzzeit-Memory.
</details>
<details><summary>Teamregeln</summary>
Agenten sollen intern Informationen austauschen können, aber User-Audio bleibt exklusiv. Der Orchestrator entscheidet, wer die finale Antwort liefert.
</details>
<details><summary>Neue Agents</summary>
Ein Agent kann zunächst nur über `config/agents.json` hinzugefügt werden. Speziallogik kann später als eigenes Modul ergänzt werden.
</details>
